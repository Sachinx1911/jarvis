# Profile interview

Questions asked by `jarvis interview`. Each answer is saved as a memory in the user's own words.
Edit freely; only lines starting with "- " are asked.

- What should Jarvis call you, and which languages do you prefer to use?
- What do you do for work or study? Name the main projects you are working on.
- Which city do you live in, and what is your usual daily schedule?
- Which 5 things should Jarvis do for you every day?
- How do you like answers: short points, or detailed explanations?
- Is there anything Jarvis must never do without asking you first?
- Which apps and tools do you use most on your laptop?
- Any other thing Jarvis should always remember about you?
